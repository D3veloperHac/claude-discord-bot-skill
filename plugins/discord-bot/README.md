# Claude Discord Bot Plugin

This directory is an installable Claude Code plugin. The marketplace catalog is at the repository root in `.claude-plugin/marketplace.json`.

Plugin contents:

- `.claude-plugin/plugin.json` — plugin metadata
- `skills/discord-bot/SKILL.md` — Discord bot development skill

The skill covers architecture, Gateway and REST selection, intents, application commands, components, interaction verification/deadlines, permissions, security, privacy, rate limits, and production reliability. It directs Claude to verify details against official documentation when platform requirements may have changed.
